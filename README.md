Leonida Legend is an offline GTA VI trophy guide and tracker that runs entirely in the browser: it covers all 55 official PlayStation 5 trophies, each with its official name and description plus an original guide whose strategy specifics are cited from named sources (Exophase, PSNProfiles, PowerPyx), flags the missable trophies, and lays out a five-stage roadmap to the platinum. The tracker lets you tick off earned trophies with kind, grade and search filters, a spoiler mode that keeps hidden trophies hidden until you earn them, and progress saved in the browser (localStorage) with one-click export and import — no account, no network, no build step.

## Run it

```sh
node serve.ts
```
(then open http://localhost:8080)
